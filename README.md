# NovaSMP Landing Page

This repository contains the source files for a polished, dark‑themed landing page for the fictional Minecraft server **NovaSMP**.

## Features
- Dark Minecraft‑inspired design
- Hero section with server name and IP address
- About section describing the server
- Features section highlighting gameplay elements
- Discord call‑to‑action button
- Fully responsive layout for mobile and desktop
- Pure HTML, CSS, and JavaScript (no external frameworks)

## Files
- `index.html` – Main page markup
- `style.css` – Styling for dark theme and responsiveness
- `script.js` – Small JavaScript for interactive elements (e.g., copy IP)

## Usage
Open `index.html` in a browser to view the landing page.
